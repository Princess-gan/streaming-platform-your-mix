# Streaming Platform — Your Mix

An interactive product portfolio prototype by Lucy exploring a simpler way to find something to watch.

Your Mix moves from familiar shows into Friday-night picks, nostalgic favorites, friends' discoveries, and trending titles. A brief cover leads into a muted video preview, with a clear choice to select the title or move on. Category cues and short transitions help viewers understand why a title appears.

## Prototype scope

- HTML, CSS, and JavaScript; no build step or backend required.
- Official YouTube clips and trailers embedded through the IFrame API; availability depends on the publisher and region.
- Sample viewing history, friends, and recommendation contexts demonstrate the experience; they are not live user data or a production recommendation model.
- Full-episode playback is a simulated handoff, not a licensed streaming service.
- Film artwork and embedded videos belong to their respective rights holders.

## Run locally

From this directory, run `python3 -m http.server 4173` and open `http://localhost:4173`.

## Deployment

GitHub Pages serves the `main` branch from the repository root.
